# 每日四象限

一个带账号登录、跨设备同步和主动提醒的四象限任务工具。每天追问截止日期与完成情况，第二天自动增补并提醒。

## 功能

- 重要且紧急 / 重要不紧急 / 不重要但紧急 / 不重要不紧急 四象限分类
- 新增任务时强制填写期望截止日期
- 未完成的任务自动顺延，累计顺延次数
- 逾期任务自动移入「重要且紧急」
- 顺延 3 次以上追加拆分或删除提醒
- 下次打开时逐条回顾上次未完成任务的完成情况和截止日期
- 主动提醒：截止前 7 / 3 / 1 / 0 天，以及逾期 1 / 3 天
- 浏览器 Web Push 与微信 PushPlus 双渠道，同日同任务不重复推送
- 账号注册登录，数据按用户隔离
- 邮箱唯一绑定，管理员可在网页内开启邮箱验证码注册
- 导入 / 导出 JSON 备份

## 技术栈

- 后端：Python 标准库 HTTP 服务 + SQLite，无第三方 Python 依赖
- 推送：openssl 生成 P-256 密钥并做 ES256 VAPID 签名，空 payload Web Push
- 微信：PushPlus `/send` 接口，用户在网页内配置 token，token 不回显
- 前端：原生 HTML / CSS / JavaScript，Service Worker 处理通知

## 本地运行

```bash
python3 server.py
```

默认监听 `3000` 端口，可用 `PORT` 环境变量覆盖。首次启动会自动创建 `data.db` 和 `vapid_private.pem`。

**首次使用**：第一个注册的账号自动成为管理员。登录后页面底部出现「站点设置」，填入自己的邮箱 SMTP 地址和授权码（QQ / 163 邮箱在网页版设置里开启 SMTP 后获取，不是登录密码），点保存会发一封测试邮件。收到后邮箱验证即开启，之后所有新注册都要先收验证码。授权码只存服务端，接口不回显，也不需要写进环境变量。

## 配置微信提醒

1. 打开 https://www.pushplus.plus/ ，微信扫码登录
2. 完成实名认证（免费版调用接口的前提）
3. 在「一对一推送」页面复制你的 token
4. 登录本站，在「微信提醒」面板粘贴 token，选择渠道并保存
5. 点「发送测试」确认微信收到消息

免费版每天 200 条，个人使用足够。可选渠道：`wechat`（微信公众号，默认）、`clawbot`、`app`、`mail`、`webhook`。

## 配置浏览器推送

登录后在「今日提醒」面板点「开启主动提醒」，授权通知即可。iOS Safari 需要先把网站添加到主屏幕；国内安卓 Chrome 依赖 Google 推送通道，通常无法送达，建议走微信渠道。

## 部署

服务必须监听 `PORT` 环境变量并绑定 `0.0.0.0`。任意支持 Python 的主机都能跑：

```bash
PORT=3000 python3 server.py
```

反向代理需要把 HTTPS 正确转发到后端，否则浏览器推送无法注册。

## 数据与安全

- 密码用 PBKDF2-HMAC-SHA256 加盐哈希存储，会话用 HttpOnly Cookie
- `data.db` 和 `vapid_private.pem` 是运行时文件，已加入 `.gitignore`，不要提交
- 微信 token 只写入服务端数据库，任何接口都不返回 token 原文
- 部署环境的数据库文件不保证永久保留，重要数据请定期用「导出」备份

## 已知限制

- 没有桌面小组件。Widget 是 Android AppWidgetProvider / iOS WidgetKit 的原生能力，纯 Web 无法实现
- 微信提醒依赖 PushPlus 第三方服务，免费版有额度与频率限制
- 定时任务粒度为 10 分钟，不是秒级
